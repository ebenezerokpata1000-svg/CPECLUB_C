CPECLUB_C - Week 1 Projects

This repository contains three beginner-level C programming projects focused on translating logical problem-solving into executable code.

Projects

1. Linear Algebra Solver (Cramer's Rule)

A program that solves a system of two linear equations using Cramer's Rule.

Features:

- Accepts six coefficients (a, b, c, d, e, f)
- Computes determinant
- Handles cases where no unique solution exists
- Outputs results to two decimal places

2. Mini Calculator

A command-line calculator that performs basic arithmetic operations.

Features:

- Supports +, -, *, /
- Uses conditional logic to determine operation
- Handles division by zero errors

3. Even/Odd Checker

A simple program that determines whether a number is even or odd.

Features:

- Uses modulo operator (%)
- Accepts integer input
- Outputs classification

Concepts Learned

- Input and Output in C ("printf", "scanf")
- Data types ("int", "double", "char")
- Conditional statements ("if", "else", "switch")
- Basic arithmetic operations
- Error handling
